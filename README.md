# 卫戍协议 · 干员卡池筛选

> 选完本局的禁用词条，立刻看清这一局到底能出哪些干员。
> 一个网页、一个文件、双击即开，不联网也能用。

**在线使用：** <https://cccgshovel.github.io/Arknights_weishu_bantool/>

## 这是什么

《明日方舟》「卫戍协议：规程」模式里，每局会禁用若干**主盟约**和**副盟约**，禁掉之后能出的干员就从 143 名里筛掉一大半，临场再翻全靠记。

这个小工具把这件事变简单：按本局禁用情况勾一下，页面直接把**剩余可用干员按「盟约 × 阶数」摆成网格**，谁在这一局能出、出在第几阶、身上还挂着别的什么盟约，一目了然。

- 收录 **143 名**干员，覆盖 **10** 个主盟约、**15** 个副盟约、**Ⅰ~Ⅵ** 六个阶数
- 特质类型是「**持续叠加**」的干员（共 74 名）会被**加粗并打上 ★**，优先抓在眼里
- 适用本体：**2026.11.8** 更新的《卫戍协议：规程》

## 主要功能

### 1. 顶部一键选择本局禁用

主盟约选满 5 个、副盟约选满 5 个，点「生成」。选错了再点一次就取消，点「重置」清空重来。
选择会存在浏览器本地，关掉页面下次打开还在。

### 2. 概览数字

页面顶部实时给出「**可用 N 张 · 持续叠加 M 张**」，一眼知道这局池子有多大。

### 3. 五张表，各管一件事

| 表 | 内容 |
| --- | --- |
| **表1** | **可用干员**，横轴是没被禁的主盟约，纵轴 Ⅰ~Ⅵ 阶 |
| **表2** | **可用干员**，横轴是没被禁的副盟约，纵轴 Ⅰ~Ⅵ 阶 |
| **表3** | **出不了的干员**，按「被禁主盟约 × 阶数」摆开 |
| **表4** | **出不了的干员**，按「被禁副盟约 × 阶数」摆开 |
| **表5** | 可用干员的特质详情清单，默认折叠，点标题展开 |

行底色代表阶数，Ⅰ 浅灰 → Ⅵ 杏橙，配色取自官方盟约交叉表；表3 / 表4 用同色系的暖灰版，一眼能分出「这些是出不了的」。

### 4. 格子里怎么读

```
野鬃（助力）★
```

- **野鬃** = 干员名
- **（助力）** = 它除本列盟约以外的其他盟约
- **★ + 加粗** = 特质类型是「持续叠加」

一格里有多个干员时，每个干员单独占一行，名字不会被拆断。

### 5. 点名字查特质

在任意一张表里点干员名（表3、表4 的不可用干员也能点），弹出该干员的盟约、特质类型、特质（基础 / 精锐）与原型干员。按 `Esc`、点空白处或右上角 `×` 关闭。

### 6. 内置使用说明

右上角「说明」按钮里写着同样的内容，**第一次打开会自动弹一次**，之后可以随时点开。

## 判定规则

**先看主盟约，再看副盟约**：

1. 主盟约里只要**有一个没被禁**，这张卡本局就能出 —— 此时不再看副盟约。
2. 主盟约**被全禁**，直接出不了，副盟约再干净也没用。
3. 只有**本来没有主盟约**的干员，才看副盟约：副盟约被全禁才出不了。

所以带多个主盟约的干员会在表1 的多列重复出现，这是规则本身导致的，不是重复计算。

## 怎么用

**在线**：直接打开 <https://cccgshovel.github.io/Arknights_weishu_bantool/>

**离线**：下载仓库里的 `index.html`（或 `干员卡池.html`，两者内容相同）双击打开即可 —— **单文件、零依赖、不联网**，路径里带中文也没关系。

然后：

1. 勾选本局被禁的 **5 个主盟约 + 5 个副盟约**
2. 点「生成」
3. 对着表1 / 表2 选卡；点名字看特质
4. 下一局点「重置」，重新勾

> 换浏览器或清缓存会丢已选内容，重点一遍就行。

## 特性

- **单文件**：整个工具就是一个 HTML，没有安装、没有依赖、没有构建
- **离线可用**：断网照常跑，只有想点数据来源链接时才需要网络
- **本地保存**：禁用选择存在浏览器 localStorage
- **打印友好**：表5 在打印时会自动展开

## 数据与版本

- 数据来源：[PRTS 明日方舟中文维基](https://prts.wiki/)，整理为 `卫戍协议_干员数据库.csv` 与 `卫戍协议_盟约交叉表.xlsx`「按阶明细」
- 工具版本：**v1.4.3**
- 游戏本体更新后数据可能过期，以游戏内实际为准

